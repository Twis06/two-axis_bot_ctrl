# Archive: published evidence before R4 republication (2026-09-24)

Byte-for-byte copies of the evidence files that R4 regenerates, as they were at
commit `5c4880b`. They are kept so historical tables stay available after
republication. SHA-256 of every file is in `SHA256SUMS`.

- `task4b_*` are the Packet 4B **round-1** evidence (the round-2 source had not been republished).
- `task3_ceiling_*` were scored with the pre-R1 completion scorer (calibration could credit test waypoints).
- `task5*` are the pre-R2 analysis (mixed windows; a torque value under a current name).
- `task2_*`, `task3_estimator_audit.*` carry metrics version 4A.3 run_ids.

Do not cite these as current results; see the regenerated files in `report/`.
