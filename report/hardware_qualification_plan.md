# Hardware qualification plan: head-roll axis, frozen baseline `7d857df507c389c9`

**Status: Proposed, not performed.** Limits below are provisional project values, to be confirmed against the real application and fixture. Passing qualifies the tested envelope only; the adaptive correction is not hardware-tested unless it first passes a new registered simulation comparison.

**Instrumentation** (one timebase, ≥ 1 kHz): roll and yaw encoders; current target, pre-clamp command, measured current and active limit; bus voltage, phase voltage/PWM duty and temperature; CAN send/receive timestamps; drive mode and fault state; original and governed references. Fixture: calibrated torque sensor, hard-wired e-stop independent of the host, supported load, verified clearance, and mechanical stops or a verified brake.

**Global abort triggers:** stale/lost feedback timestamps; wrong torque sign or unexpected current/voltage behavior; tracking error > 5°; ≥ 95% current utilization for > 100 ms; unexplained latched fault; fixture temperature limit (below the simulated 130 °C trip); motion outside verified clearance. End the test and isolate actuation. Communication loss gives **drive-local damping only**, which does not hold against gravity; there is **no promised position hold** after feedback loss or e-stop, so the support, brake or stops must contain motion (simulated loaded outage: up to 42°, a warning, not a bound).
