# Hardware qualification plan: head-roll axis, frozen baseline `7d857df507c389c9`

**Status: Proposed, not performed.** Limits below are provisional project values, to be confirmed against the real application and fixture before testing.

**Instrumentation** (one timebase, ≥ 1 kHz): roll and yaw encoders; current target, pre-clamp command, measured current and active limit; bus voltage, phase voltage/PWM duty and temperature; CAN send/receive timestamps; drive mode and fault state; original and governed references. Fixture: calibrated torque sensor, host-independent hard-wired e-stop, supported load, verified clearance and mechanical stops or an independently verified brake. Contain the possible gravity-driven travel before powered fault tests.

**Global abort triggers:** stale/lost feedback timestamps; wrong torque sign or unexpected current/voltage behavior; tracking error > 5°; ≥ 95% current utilization for > 100 ms; unexplained latched fault; fixture temperature limit (below the simulated 130 °C trip); motion outside verified clearance. End the test and isolate actuation as the fixture procedure requires. Communication loss invokes **drive-local damping**, which does not hold against gravity; tracking-fault catch can hold only while feedback and actuation remain available. Feedback loss or e-stop has **no promised active position hold**: the support, brake or stops must contain motion. The loaded 100 ms simulation outage moved up to 42°; this is a warning, not a hardware excursion bound.
