# Outside references, reused code and automated tools

## Outside references

- **Assessment brief:** *Robotics Controls Technical Assessment*, the only source of plant constants and observed results. It is not redistributed in the repository.
- **No external papers, books or datasets are cited or used as data.** The methods are standard control and estimation techniques, implemented from their textbook definitions rather than taken from a specific source:
  - PI × lead loop shaping, with gain and phase margins and delay margin;
  - Tustin (bilinear) discretization;
  - constant-acceleration Kalman filtering;
  - conditional-integration anti-windup;
  - minimum-jerk (quintic) trajectories;
  - ridge-regularized least squares;
  - RK4 integration.

## Reused code

**No third-party source code was copied into the repository.** Everything in `sim/`, `ctrl/`, `exp/`, `analysis/` and `tests/` was written for this assessment. The libraries used as dependencies, unmodified, are:

| Library | Use |
|---|---|
| Python 3.9 standard library | `unittest`, `json`, `hashlib`, `concurrent.futures`, `dataclasses`, … |
| NumPy 2.0 | arrays, linear algebra, random draws |
| SciPy 1.13 | `scipy.optimize`, `scipy.interpolate`, `scipy.special` in the analysis and simulator helpers |
| Matplotlib 3.9 | plots in `report/figs/` |
| Python-Markdown (report build only) | `report/html_assets/build_report.py` → `assessment_report.html` |

Versions are recorded in every run manifest and in `report/reproduction_log.txt`.

## Automated tools

| Claude Code (Anthropic; Claude models) | Planning; simulator, controller and experiment code; corrective packets R1–R4; the prospective Task 5 test (predictor, registration, execution); the reconciliation of the written answers; this memo, the qualification plan and this note. Sub-agents performed the packet reviews, and the implementing agent did not review its own packets. |

Its later edits were checked by independent review rounds (R6). |
